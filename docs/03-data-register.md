# 03b · Data register

Companion to 03-research-brief.md. Researched 2026-10-17 from official pages; nothing downloaded. This becomes `docs/DATA_REGISTER.md` in the repo; every sensor-profile or threat parameter cites a register ID.

**Usage policy (applies to every row):**
1. **Parameters, not payloads.** By default we derive numeric parameters (RCS ranges, band plans, blade-pass harmonics, apparent-size curves) from these sources and cite them. We do not ship raw clips.
2. **Redistribution only under an open licence.** Raw samples go in the repo or a pack only if the data licence is CC0, CC BY, ODbL (with attribution and share-alike) or equivalent, *and* the licence is confirmed on the page.
3. **Restricted sources stay local.** NC/R (non-commercial / research-only) and "not stated" sources may be consulted for calibration under research use. They are never redistributed and never shown as clips in the deck.
4. Licence status is re-checked before each release (RELEASE.md step).


Researched 2026-10-17. Nothing was downloaded. "Licence: not stated" means the official page names no licence. A repo code licence (MIT/Apache) is listed separately and should NOT be read as covering the data. **NC/R** = non-commercial or research-only restriction.

## Notes per item

- **D01-D03 Anti-UAV family.** Only Anti-UAV300 has RGB and IR. 410 and 600 are IR-only ([ZhaoJ9014 repo](https://github.com/ZhaoJ9014/Anti-UAV)). v1 paper: 318 RGB-T pairs, >580k boxes, "released publicly for academic research" ([arXiv 2101.08466](https://arxiv.org/pdf/2101.08466)). A later paper says "over 297K annotated RGB-Thermal frames" ([arXiv 2306.15767](https://www.arxiv.org/pdf/2306.15767)). Anti-UAV410 (TPAMI 2024, DOI 10.1109/TPAMI.2023.3335338): 410 videos, >438K boxes ([BIT](https://pure.bit.edu.cn/en/publications/anti-uav410-a-thermal-infrared-benchmark-and-customized-scheme-fo/)). The MIT licence applies to the code repo. No dataset licence was found.
- **D04 DUT Anti-UAV.** Sizes from [ar5iv 2205.10851](https://ar5iv.labs.arxiv.org/html/2205.10851). Downloads (Google Drive/Baidu) are on the [repo](https://github.com/wangdongdut/DUT-Anti-UAV), which is Apache-2.0.
- **D05 MAV-VID.** Counts from the [benchmark repo](https://github.com/KostadinovShalon/UAVDetectionTrackingBenchmark), which notes the Kaggle site "seems to stop working". There is a Bitbucket mirror. The Kaggle licence could not be read.
- **D06 Drone-vs-Bird.** "sign a data usage agreement and can then use the data for research purposes" ([wosdetc/challenge](https://github.com/wosdetc/challenge)). ICASSP 2023 review: "openly available to the research community, for non-commercial purposes" ([DOAJ](https://doaj.org/article/c668ba4d64d54715b62e639cdee0b95c)). The dataset grows each edition, so the current size is UNVERIFIED.
- **D07 Det-Fly.** [RA-L 2021 paper](https://shiyuzhao.westlake.edu.cn/2020IEEEye.pdf); downloads via OneDrive/Baidu on the [repo](https://github.com/Jake-WU/Det-Fly).
- **D08 DroneRF.** Receivers: 40 MHz instantaneous bandwidth each, max 200 MS/s; CSV time-domain amplitude, 1M samples per part ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC6727013)). The Mendeley page licence field appeared blank when fetched. Recheck before redistributing.
- **D09 CardRF.** "over 65 GB". The page gives no sampling rate; the implied rate is implausible, so check CardRF.pdf ([DataPort](https://ieee-dataport.org/documents/cardinal-rf-cardrf-outdoor-uavuasdrone-rf-signals-bluetooth-and-wifi-signals-dataset)).
- **D10 DroneAudioDataset.** Indoor recordings, so outdoor realism is limited. Durations and sample rate are from the [Sensors 2021 paper](https://www.mdpi.com/1424-8220/21/15/4953). The [repo](https://github.com/saraalemadi/DroneAudioDataset) has no LICENSE.
- **D11 DREGON.** "The data are free to use for academic and educational purpose" ([dregon.inria.fr](http://dregon.inria.fr)). The IROS 2018 paper was not accessible.
- **D12 Svanström multi-sensor.** Daylight only, max 200 m ([arXiv 2111.01888](https://arxiv.org/pdf/2111.01888)); Zenodo licence "Other (Open)" ([Zenodo](https://zenodo.org/records/5500576)).
- **D13 DIAT-µSAT.** Indian (DIAT Pune) X-band CW radar. The .mat files are on request for educational use ([DataPort](https://ieee-dataport.org/documents/diat-msat-micro-doppler-signature-dataset-small-unmanned-aerial-vehicle-suav)).
- **D14 KTH/SAAB 77 GHz.** This is the cleanest licence among the radar sets (CC BY 4.0). Drones: Matrice 200 V, Mavic 2 Pro, Phantom 3, custom FPV, Tarot 680, Syma X23W ([Zenodo 5511912](https://zenodo.org/records/5511912)).
- **D15 NYU 60 GHz.** The page says a fuller description is "updated soon" ([DataPort](https://ieee-dataport.org/node/12665)).
- **D16 MAFAT.** Classes are humans vs animals only, and there are train/experiment/synthetic/background groups ([BGU paper](https://www.ee.bgu.ac.il/~haimp/2021_MAFAT_Radar_Challenge_Conference_Paper.pdf)). Useful only for ground-clutter realism.
- **D17 Real Doppler RAD-DAR.** No dataset under this name was found. The only match was a UPM research project name. Treat as UNVERIFIED and drop unless the user has a link (it may be a Kaggle upload).
- **D18 FBD-SV-2024.** Published in Scientific Data 12, 530 (2025), DOI 10.1038/s41597-025-04872-6. Mirrors on Kaggle and Baidu ([repo](https://github.com/Ziwei89/FBD-SV-2024)).
- **G01 SRTM.** [Earthdata catalog](https://www.earthdata.nasa.gov/data/catalog/lpcloud-srtmgl1-003).
- **G02 OSM.** You must credit OSM and state that the data is under ODbL ([copyright](https://www.openstreetmap.org/copyright)).
- **G03 Bhuvan/NRSC.** Paid IRS products cannot be put online, apart from small extracts up to 1024x1024 with no download ([dissemination](https://www.nrsc.gov.in/EOS_dissemination_Licensing)). The OSM wiki summarises Bhuvan's "single user license" ([wiki](https://wiki.openstreetmap.org/wiki/Open_Geospatial_Data_from_Government_of_India)). The Bhuvan-specific T&C page was not read directly.
- **W01 ERA5.** CC-BY ([CDS](https://cds.climate.copernicus.eu/doi/10.24381/cds.adbb2d47)). Attribute Copernicus C3S/ECMWF.
- **W02/W03 NOAA.** NODD terms: you may not imply endorsement or present modified data as original ([ISD](https://registry.opendata.aws/noaa-isd)). The older GFS bucket is deprecated; use noaa-gfs-bdp-pds.
- **W04 IMD.** Resolutions are from the [imdR docs](https://cran.r-universe.dev/imdR/doc/imdR-introduction.html). The OGD platform says GODL "allows users to consume datasets ... for commercial as well as non-commercial purposes" ([OGD PDF](https://app.indiapost.gov.in/documents/media/OGD.pdf)). The GODL page itself was robots-blocked.
- **X01 UAV Database.** CC0, DataverseNO ([B2FIND](https://b2find.eudat.eu/dataset/454c5a71-a8db-5136-bfa4-e29e62d5652a)). Its 93 UAVs skew toward fixed-wing/research types; this is UNVERIFIED.
