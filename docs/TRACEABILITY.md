# Requirements traceability

Working copy of the table in [06-requirements-traceability.md](06-requirements-traceability.md), which stays as the planning record. This file is the live one: the **Built proof** column is filled as features land, with a test ID, a measured metric in [PERFORMANCE.md](PERFORMANCE.md) or pilot data, or a demo timestamp. A dash means nothing is built yet for that clause.

Proof types: **T** automated test in CI · **M** measured metric (own pilot or benchmark) · **D** shown in the 10-minute demo (see [08-demo.md](08-demo.md)) · **Doc** documented artefact.
